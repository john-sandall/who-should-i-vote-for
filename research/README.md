**Borough-level picture (PollCheck projection):**
- Labour: 54.7% (2022) → ~37% projected; 44 → ~28 seats. Still likely largest.
- Greens: 22.0% → ~34% projected; 3 → ~20 seats. The major insurgent.
- Lib Dems: 11.8% → ~13%; 0 → ~2 seats.
- Reform: ~8% (new).
- Conservatives: 11.2% → ~5%.
- Bunhill is not flagged as a top-5 marginal — Labour expected to retain. But polls vs. reality often diverge in low-turnout wards (Bunhill turnout was 30.3% in 2022, the lowest in the borough).

## How to read this dossier

Each party file follows the same structure:
1. **What they're pledging in 2026** — concrete commitments
2. **Their record / track record** where applicable
3. **Bunhill candidates** — who's standing locally and what's known about them

The scorecard scores Labour against its own 2022 manifesto using public sources only (Housing Ombudsman rulings, council annual reports, council budget docs, local press). Where a pledge has multiple interpretations, the most generous reading is used.

The HTML app at `../index.html` is the human-friendly summary. The markdown files are the receipts.

> **A note on neutrality:** Every party gets the same template, the same depth where information is available, and the same scrutiny. Where information is genuinely missing for a smaller party (Reform, SDP), that gap is stated rather than papered over. Quotes from candidates' own materials are clearly attributed.
